## Tutor LMS Full Setup Workflow

1. Verify Tutor LMS plugin active + version >= 2.x
2. Create course category taxonomy (if custom needed)
3. Create ACF field group for tutor_course CPT
4. Set up template overrides directory: /theme/tutor/
5. Override single-course template with site branding
6. Add Course schema via Yoast (use yoast-schema skill)
7. Set up Falang for course title/description translation
8. Create custom enrollment redirect page
9. Set up course completion certificate template
10. Test enrollment flow end-to-end
