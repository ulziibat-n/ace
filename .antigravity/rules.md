# Design Fidelity Rules

- **DESIGN FIDELITY RULE**: When the user provides a UI mockup, static HTML/Tailwind files, or screenshots, you are STRICTLY PROHIBITED from inventing or hallucinating new CSS classes, colors, or layouts. Your only job is to translate the provided visual exactness into dynamic WordPress PHP files (e.g., breaking into template-parts). Any deviation from the provided design is a critical failure.
